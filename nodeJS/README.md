# NodeJS API

## Endpoints GET

### /professor/subjects

Returns all subjects of the professor.

### /professor/subject/:id

Returns a subject of the professor.

### /professor/subject/:id/practices

Returns all practices of the subject.

### /users

Returns all users.

## Endpoints POST

### /login

Returns a token.

### /logout

Removes the token.

### /signup

Returns a user.

### /subject/:id/create

Create a practice for the subject.
